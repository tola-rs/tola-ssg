# Tola

A Typst-based static site generator.

[Website](https://tola.build) · [中文](<README-zh.md>)

## Help

- `tola --help` — CLI commands.
- `tola help` — Configuration and package reference.
- `tola skill` — [Authoring guide](<TOLA-SKILL.md>), read by task: `tola skill math`, `tola skill headings levels`. Use `--list` for the heading tree and `--all` for full text.
